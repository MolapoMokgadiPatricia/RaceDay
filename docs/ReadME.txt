# RaceDay System

## PROG6212 Programming 2B – Part 1

## System Description

RaceDay is a race event management system designed to connect organisers and participants through a single platform. Organisers can create running events, manage race categories, approve enrolments, and record race results. Participants can register, update their profiles, enrol in race categories, and view their personal race results.

The system follows a role-based design where each user is assigned either an **Organiser** or **Participant** role.

## User Roles

### Organiser

Organisers can:

* Create and manage events.
* Create and manage race categories.
* View participant enrolments.
* Update enrolment status.
* Record race results.

### Participant

Participants can:

* Register an account.
* Log into the system.
* Update their profile.
* Enrol in race events.
* View their race results.
